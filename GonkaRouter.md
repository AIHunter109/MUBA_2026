Hackathon Challenge: AI for Society 
1. Challenge Overview
Goal: 
This challenge focuses on real-world applications of AI in the public domain. Participants are encouraged to use the Gonka Network to build tools with genuine value for everyday users. The challenge is open-ended — the following directions are provided as inspiration, not constraints: 
AI Fact Checker — Cross-verify news and social media content using multiple models, producing an on-chain Truth Score with a fully traceable reasoning trail.
Multilingual AI Public Assistant — A censorship-free AI access layer covering education, medical consultation, legal literacy, and more, designed for non-English-speaking communities worldwide.
AI Accessibility Tools — AI-powered assistants designed for users with visual, hearing, or cognitive impairments.
Open Knowledge Engine — A decentralized Q&A or knowledge retrieval system built on Gonka inference.
Take AI Fact Checker as an example, which is a preferred application. The following information helps you understand the background, the requirements, the tips, the criteria, etc. 

What you are building is a decentralized "Truth Engine" that uses multi-model AI inference to verify the authenticity of news, social media claims, or digital media (text/images) in real-time. 

In an era of deepfakes and AI-generated misinformation, centralized fact-checkers are often accused of bias. This challenge tasks you with using Gonka’s decentralized network to provide a neutral, verifiable, and transparent source of truth. 

2. Technical Requirements | 技术要求
Mandatory: Gonka Router Integration (Required)
All AI reasoning and verification logic MUST run on the Gonka Network via the official inference gateway (gonkarouter.io).
Multi-Model Consensus: You are encouraged to use at least two different models to "cross-verify" claims and ensure neutrality. 
Free Access: During the hackathon, all participants will receive unlimited free token credits for development.
Core Functionality
Claim Extraction: Input a URL, tweet, or text snippet for verification.
Decentralized Verification: Use Gonka-hosted models to analyze the claim against real-time web data or internal knowledge bases.
Truth Score & Reasoning: Output a "Truth Score" (0-100%) and a detailed "Reasoning Trace" explaining the verdict
Transparency UI: A dashboard showing the verification result and the specific Gonka Request IDs for each inference step.

3. Developer Tips & Best Practices
The "Neutrality" Prompt: Design prompts that instruct the models to be objective and cite specific evidence for their conclusions.
Cross-Model Comparison: If two models disagree, how does your system handle the conflict? Building a "Consensus Logic" is a major plus.
On-Chain Proof: Always display the Gonka Request ID to prove that the "Truth" wasn't generated by a centralized server.
